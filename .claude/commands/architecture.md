# Architecture Review

Review the current project architecture.

Focus on:

- Separation of concerns
- SOLID principles
- Coupling and cohesion
- Dependency flow
- Layer boundaries
- Reusability
- Scalability
- Maintainability

Identify:

- Architectural smells
- Unnecessary complexity
- Violations of best practices

For each issue provide:

- Severity
- Explanation
- Recommended improvement

End with:

1. Architecture score (/10)
2. Top 5 architectural improvements
3. Whether the current design can support future growth without major redesign.
