# Performance Review

Analyze the current implementation for performance bottlenecks.

Focus on:

- Time complexity
- Memory usage
- Database queries
- File I/O
- Network/API calls
- Model loading
- Caching opportunities
- Parallelism/async
- Unnecessary work

For each issue provide:

- Severity
- Root cause
- Expected impact
- Recommended optimization

End with:

1. Top 5 performance improvements
2. Estimated performance gain
3. Overall performance score (/10)

Do not change architecture unless absolutely necessary.
