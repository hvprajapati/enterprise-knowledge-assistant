# Code Review

Review the current changes without modifying code.

Focus on:

- Correctness
- Bugs
- Edge cases
- Code quality
- Readability
- Maintainability
- Performance
- Best practices

For each issue provide:

- Severity
- Explanation
- Recommended fix

End with:

- Overall score (/10)
- Top 5 improvements
- Merge recommendation:
  - Approve
  - Approve with minor changes
  - Request changes
