# Security Review

Review the current implementation for security issues.

Focus on:

- Authentication
- Authorization
- Input validation
- File handling
- Secrets management
- SQL injection
- Prompt injection
- API security
- Error handling
- Sensitive data exposure

For each issue provide:

- Severity
- Risk
- Recommended fix

End with:

1. Security score (/10)
2. Top 5 security risks
3. Production readiness assessment
