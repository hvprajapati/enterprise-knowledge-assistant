# Test Review

Review the current code for test coverage.

Focus on:

- Missing unit tests
- Missing integration tests
- Edge cases
- Error handling
- Mocking
- Test quality
- Coverage gaps

If tests are missing:

- Generate production-quality tests.
- Reuse existing fixtures where possible.
- Do not modify production code unless required for testability.

End with:

1. Coverage assessment
2. Critical missing tests
3. Test quality score (/10)
